# Full Stack Open – Part 10: React Native

This repository contains my personal study project for **Part 10: React Native** of the [Full Stack Open](https://fullstackopen.com/) course.

## 📱 What This Part Is About

In this part, I learned how to build native Android and iOS mobile applications using **JavaScript** and **React Native**. The goal was to understand how to render native UI components, create smooth user experiences, interact with backend servers, and test mobile apps — all within the React Native framework.

## 💡 What I Learned

### a. Introduction to React Native  
- What React Native is and how it differs from regular React  
- Setting up the development environment (Expo)  
- Rendering native components like `View`, `Text`, `Image`, `ScrollView`, etc.

### b. React Native Basics  
- Styling components using `StyleSheet`  
- Flexbox layout in mobile apps  
- Navigation using React Navigation  
- Managing component state and props  
- Building interactive and responsive views

### c. Communicating with Server  
- Fetching data using REST APIs  
- Axios and async/await in React Native  
- Handling loading, error, and success states  
- Submitting user input and updating views accordingly

### d. Testing and Extending Our Application  
- Unit testing components using the React Native Testing Library  
- Writing integration tests  
- Structuring a larger React Native app  
- Enhancing usability and performance

## 🛠️ Tools & Technologies Used

- **React Native (with Expo)**  
- **React Navigation**  
- **Axios** for HTTP requests  
- **React Native Testing Library**  
- **Node.js v20**  
- **rate-repository-api** backend (provided by the course)

## 📁 About This Repo

This repo includes my code for all four sections of Part 10. It was a great experience to build a mobile app from scratch and apply many of the same principles from web development in a new context. I also learned how React Native projects are structured and how to create user-friendly and fully functional mobile applications using JavaScript.
